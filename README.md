## 강의 개요
이 강의는 인공지능(AI)과 자동화 도구를 활용해서, 새로운 웹이나 앱 서비스를 스스로 기획하고, 디자인하고, 직접 만들어보는 수업입니다.  ‘바이브 코딩(vibe coding)/에이전틱 코딩(agentic coding)’ 툴을 사용해서, 여러분이 생각한 아이디어를 빠르게 실제 서비스로 만들어 볼 수 있습니다. AI가 코드를 만들게하고 여러분은 에이전트의 결과에 대한 피드백과 워크플로우을 제공하게 됩니다. 어렵고 소모적인 업무는 AI가 맡아서 처리해주니까, 여러분은 아이디어를 실현하는데 집중할 수 있습니다.  수업에서 개발과 LLM의 기초 개요도 가르치니 비개발자도 따라올 수 있도록 구성하였습니다.
이 수업을 통해 여러분은 문제를 발견해서 직접 기획하고 팀과 함께 실습하고 결과물을 실제로 만들어 발표하는 실전 경험을 쌓게 됩니다. AI와 최신 도구를 자유롭게 쓰면서, 스타트업이 당면한 문제를 스스로 해결할 수 있는 진짜 실무 능력을 키우는 게 이 강의의 목표입니다.

## 강의 목표
이 수업을 수강한 후, 학생들은 다음과 같은 역량을 갖추게 됩니다:

- 실무형 창업가 역량  
  스타트업 현장에서 실제로 쓰이는 도구와 방법을 경험하며, 실전에서 바로 활용할 수 있는 자신감을 기릅니다.  
- AI 기반 서비스 개발 역량  
  AI 코딩 도구를 활용해, 웹/앱 서비스를 스스로 기획하고 디자인하며 개발할 수 있습니다.  
- AI·자동화 기술 활용 역량  
  LLM 과 에이전틱 AI 도구를 활용해 에이전트 본인이 필요한 AI 에이전트를 스스로 만들 수 있습니다.
- 문제 해결 및 협업 역량  
  팀 프로젝트와 실습을 통해, 문제를 직접 정의하고 해결하며, 동료와 협업하는 경험을 쌓습니다.  

**핵심 역량**

- 서비스 설계 및 구현 능력 30%

## 성적 산출

### 출석 평가(20점)

출석은 **감점제**로 평가합니다.

#### 출석 규칙

* 결석 1회당 9점을 감점합니다. 단, 공결은 감점하지 않습니다.
* 지각 1회당 3점을 감점합니다. 단, **지각 1회까지는 감점하지 않습니다.**
  * 수업 시작 10분 후 수업에 참여하는 경우 지각으로 간주합니다.
  * 수업 시작 1시간 이후에 도착하는 경우 결석으로 간주합니다.
* 결석 3회부터는 나머지 성적에 관계없이 A학점을 받을 수 없습니다.
* 결석 4회는 학칙에 의해 학점 부여가 불가능하며 F학점이 부여됩니다.

### 과제 평가 (80점)

과제와 발표는는 아래처럼 팀순위와 개인 기여도를 반영하여 평가합니다.

#### 팀별 순위 점수

각 발표별로 학생들의 투표와 교수 평가를 합산하여 팀별 순위를 산출합니다.

* 1위 : 50점
* 2위 : 40점
* 3~4위 : 30점
* 5~6위 : 20점
* 그 외 : 10점

#### 팀내 기여도 점수

발표 직후 팀원 전원이 설문에 참여하며, **팀원 N명에게 합계 100점을 배분**합니다.

개인이 팀원들로부터 받은 평균 기여도 점수를 팀 인원수에 따른 **정규화 기준점**과 비교하여 50점 만점으로 환산합니다.

> 정규화 기준점 = 100 ÷ 팀원 수(N)
> 예) 3인 팀 : 33.3점 / 4인 팀 : 25.0점

| 정규화 기준점 대비 개인 기여도 | 기여도 점수 |
| :---------------- | -----: |
| 140% 이상           |    50점 |
| 120% 이상 ~ 140% 미만 |    45점 |
| 100% 이상 ~ 120% 미만 |    40점 |
| 80% 이상 ~ 100% 미만  |    30점 |
| 60% 이상 ~ 80% 미만   |    20점 |
| 60% 미만            |    10점 |

#### 1~6차 과제 평가 - 각 8점 만점

`(팀별 순위 점수 + 팀내 기여도 점수) × 0.8`

#### 중간 팀 발표(10월 20일) 평가 - 16점 만점

`(팀별 순위 점수 + 팀내 기여도 점수) × 0.16`

#### 최종 팀 발표(12월 1일) 평가 - 16점 만점

`(팀별 순위 점수 + 팀내 기여도 점수) × 0.16`
